# tests/conformance/

`sample01_multiply.asm` and `sample02_popcount.asm` are the two fully
deterministic worked examples from the spec's Appendix B (B.1 and
B.2) -- no I/O, no preloaded data memory, so their expected results
are unambiguous. Both are verified in this template: assembling and
running them through `tools/dsd8sim.py` reproduces the documented
final state exactly (R3 = 91 / LEDs = 0x5B / 51 instructions for the
multiply; R2 = 6 / 44 instructions for the population count).

**These two samples are not the official 40-program conformance
suite** (T01-T40, Section 8.4) -- that suite is the instructor's
separate, confidential grading artifact, distributed alongside this
template rather than generated by it. What these two samples are for:

- proving the whole pipeline works end to end (assemble -> golden
  trace -> RTL simulation -> diff) before the real suite exists,
- giving every team something to point `make conformance` at from day
  one,
- being a second sanity check on `tools/dsd8asm.py` and
  `tools/dsd8sim.py` themselves, independent of the appendix B.3
  (bubble sort, needs a preloaded data memory) and B.4 (UART echo,
  needs timed stimulus) examples this template does not attempt to
  reproduce.

When the instructor's real T01-T40 suite is distributed, drop its
`.asm` files (and, if supplied separately, its golden `.trace` files)
into this directory and `run_conformance.py` will pick them up
automatically -- no code changes needed.
